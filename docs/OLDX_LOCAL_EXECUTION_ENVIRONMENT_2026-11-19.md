## 1. Do not confuse the two shells

| Tool / location | What it is | What it can do with prerequisites | Important limitation |
| --- | --- | --- | --- |
| **Google Cloud SDK Shell on Windows** | A **LOCAL Windows Command Prompt** launched with the Google Cloud CLI, as observed at `D:\\Temp>`. It is **not** Google's browser-hosted Cloud Shell. | Local Git, Node/npm, Chrome/Playwright, local repo builds/tests, and `gcloud`/Firebase CLI when installed, authenticated and explicitly authorized; can call Google APIs under that identity. | Local CLI availability does NOT prove active owner identity, IAM access, allowed project, enabled APIs, no spend or rollback readiness. There is no Cloud Shell weekly-hour quota for local processes. |
| **WSL Ubuntu on owner's Windows laptop** | Separate local Linux filesystem/process environment accessed via WSL; previously used for ORAS/Cosign and offline OCI/attestation analysis. | Linux Bash, existing pinned security tools, and Docker/BuildKit/Grype **if individually installed and verified**, using actual local scratch capacity. | WSL HOME is **not** hosted Cloud Shell HOME; WSL toolchain/OCI evidence is not automatically signed source provenance, staging approval or a current image scan. |
| **Google-hosted Cloud Shell** | A remote Google-maintained Linux session with its **own persistent HOME** and service quota. | Existing private R2/pre-B1 preimage, relevant owner-authenticated cloud preflight and guarded recovery, if service quota/session is available. | The stored private preimage is **not present automatically** in Windows SDK Shell/WSL. Hosted hours/scratch limitations do not disappear merely because local SDK Shell is opened. |

**Principle:** Most *code and tooling* tasks can move to Windows SDK Shell / WSL, but **remote session state and private Cloud Shell files do not move automatically**. Provider-side IAM/Cloud Run, Firestore, Registry and Billing operations have the same authorization, security, budget and audit obligations whichever terminal sends the API call; local terminal does **not** make billed operations free.
